# Pacote-de-Otimiza-o-para-Windows-10-11
Conjunto de scripts desenvolvidos para melhorar desempenho, estabilidade e manutenção do Windows 10 e 11 de forma rápida e prática. O pacote inclui ferramentas de verificação de integridade do sistema e otimizações voltadas para redução de processos e recursos desnecessários do Windows.

Verificação de Integridade

Script responsável por analisar e reparar possíveis corrupções do sistema utilizando ferramentas nativas do Windows, incluindo:

*SFC /scannow
*DISM RestoreHealth
*Verificação de arquivos do sistema
*Correção automática de componentes corrompidos

Otimização de Serviços e Recursos
Inclui:

desativação de telemetria
redução de serviços em segundo plano
otimizações de inicialização
ajustes de desempenho
redução de processos desnecessários
melhorias para PCs modestos e hardware antigo

Objetivo:

melhorar fluidez
reduzir uso de recursos
acelerar inicialização do sistema
aumentar responsividade geral

Script de otimização focado em reduzir consumo de memória, disco e processos em segundo plano através da desativação de funções consideradas não essenciais ou arbitrárias para muitos usuários.

Execução

Os scripts devem ser executados como administrador para funcionamento completo.
